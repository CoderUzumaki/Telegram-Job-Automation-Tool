# ADR-0005: Validated external application actions

Status: Recorded specification baseline; implementation verification pending
Owner: Project maintainer
Date: 2026-10-23
Reference: JR-002; LLD §§7,12,14

## Context

Preserve the approved MVP boundaries while allowing requirements and adapters to change independently.

## Decision

Worker returns a validated destination tied to a known job. Rust revalidates http/https or a generated mail composer destination before invoking an OS handler. Never interpret content as executable paths, shell commands or arbitrary mail headers. Opening records an event; APPLIED requires explicit user confirmation.

## Consequences and alternatives

Browser launch cannot prove application submission. Keep native opening behind a platform port and tracking transitions in domain/application services.

## Verification

D07/U01/E03 cover unsafe schemes, disabled invalid actions and manual status confirmation. No automated outreach.

## Supersession

No replacement. Material changes require a new ADR and corresponding contract/test updates.
