# ADR-0003: Single database writer and transactional ports

Status: Recorded specification baseline; implementation verification pending
Owner: Project maintainer
Date: 2026-10-23
Reference: JR-002; LLD §§2.2,8,10

## Context

Preserve the approved MVP boundaries while allowing requirements and adapters to change independently.

## Decision

Only the Python worker writes SQLite. Application services depend on repository and Unit of Work ports; ORM records never become domain entities. Use short transactions, foreign keys per connection, WAL and bounded busy handling. Never share a Unit of Work across concurrent tasks. Commit source permission fences and checkpoints with associated data.

## Consequences and alternatives

One writer simplifies consistency but does not eliminate contention. Choose the SQLite execution adapter after measuring event-loop impact; that choice remains unresolved.

## Verification

JR-007 tests file-backed migrations, rollback, constraints and writer contention; ingestion tests cover revocation and crash replay.

## Supersession

No replacement. Material changes require a new ADR and corresponding contract/test updates.
