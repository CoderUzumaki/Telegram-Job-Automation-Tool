# ADR-0007: Staged native platform strategy

Status: Recorded specification baseline; implementation verification pending
Owner: Project maintainer
Date: 2026-10-23
Reference: JR-002; LLD §§2,19,21

## Context

Preserve the approved MVP boundaries while allowing requirements and adapters to change independently.

## Decision

Target Windows x64 first; design and test macOS arm64/x64 and Linux x64 early, release each only after native gates. Rust platform services own tray, credential store, paths and browser actions. Closing hides; explicit Quit drains/stops the worker. Autostart is off by default. Missing Linux tray requires an accessible window fallback; unavailable secure storage must not silently use plaintext.

## Consequences and alternatives

A shared domain does not prove native compatibility. Separate platform capability reporting from business behavior and expose actionable failures.

## Verification

JR-004/027–030 supply native smoke, session restore, packaging and signing evidence per platform.

## Supersession

No replacement. Material changes require a new ADR and corresponding contract/test updates.
