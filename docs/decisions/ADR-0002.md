# ADR-0002: Private versioned IPC

Status: Recorded specification baseline; implementation verification pending
Owner: Project maintainer
Date: 2026-10-23
Reference: JR-002; LLD §§2.3,15

## Context

Preserve the approved MVP boundaries while allowing requirements and adapters to change independently.

## Decision

Rust exclusively mediates private UTF-8 NDJSON stdin/stdout with one supervised Python worker. Use versioned schemas, a strict method allowlist, correlated responses, bounded frames and inflight requests, timeouts and bounded restarts. Stdout contains protocol frames only; sanitized diagnostics use stderr. UI cannot launch arbitrary processes.

## Consequences and alternatives

Private pipes avoid port discovery and HTTP authentication machinery. Transport must remain separate from command handlers; timeout does not imply a mutation was rolled back.

## Verification

JR-003 proves framing, handshake, invalid input rejection, timeout, restart and clean Quit. Shared schema validation prevents DTO drift.

## Supersession

No replacement. Material changes require a new ADR and corresponding contract/test updates.
