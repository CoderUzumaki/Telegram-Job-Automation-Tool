# ADR-0001: Local modular monolith without HTTP

Status: Recorded specification baseline; implementation verification pending
Owner: Project maintainer
Date: 2026-10-23
Reference: JR-002; LLD §§2–3

## Context

Preserve the approved MVP boundaries while allowing requirements and adapters to change independently.

## Decision

React owns presentation; Rust owns native services and supervision; Python owns application workflows. Pure domain modules import no UI, database, Telegram or native libraries. Compose concrete adapters at startup and inject narrow ports into use cases. Organize by feature and responsibility; split stateful orchestration from presentation components. Do not create empty abstraction layers.

## Consequences and alternatives

A localhost HTTP server adds another exposed interface and lifecycle without a second client requirement. Keep transport out of business rules.

## Verification

Unit-test policies without a process, database or network; test adapters separately.

## Supersession

No replacement. Material changes require a new ADR and corresponding contract/test updates.
